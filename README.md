# Nexus OS | Infrastructure & Telemetry Dashboard 

A modern, high-performance monitoring platform built to visualize system health, track API gateway traffic, and manage administrative security logs.

## 🚀 Features
* **Real-time Telemetry:** Dynamic charts tracking simulated system performance.
* **Infrastructure Matrix:** Regional node health monitoring with reboot simulations.
* **API Gateway Hub:** Interactive rate-limiting and endpoint traffic profiling.
* **Security Audit:** Immutable chronological event logging for system transitions.

## 🛠️ Tech Stack
* **Frontend:** React 19, TypeScript, Tailwind CSS
* **Charts:** Recharts
* **Icons:** Lucide React

## 📦 Setup
1. `npm install`
2. `npm run dev`
